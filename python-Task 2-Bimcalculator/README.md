# BMI Calculator

A simple Python program to calculate a person's Body Mass Index (BMI) and classify the result.

## Features

- Takes weight in kilograms
- Takes height in meters
- Calculates BMI using the formula:
  
  BMI = weight / (height * height)

- Displays the BMI value
- Shows the BMI category:
  - Underweight
  - Normal weight
  - Overweight
  - Obesity

## How to Run

```bash
python bmi_calculator.py
```

## Example

```text
Enter your weight in kg: 70
Enter your height in meters: 1.75
Your BMI is: 22.86
Category: Normal weight
```

## Notes

This project is a basic BMI calculator and can be expanded with a GUI, validation, or a web version.
